## 1. 目标与边界

本区域为执行平面提供原文、证据、检索、确定性指标、受控业务视图、模型端点、导出对象和备份。它按数据分类、ACL、时间快照、地域、留存和供应商策略返回数据；不把任意数据库、对象存储或第三方 Endpoint 直接暴露给 Agent。

## 2. 结构设计

~~~mermaid
flowchart LR
    S[制度/研报/公告/业务源] --> I[接入与解析]
    I --> O[OSS 原文/中间对象]
    I --> X[分块与索引]
    X --> R[ACL 检索与重排]
    R --> E[证据引用]
    B[指标服务/只读业务视图] --> C[确定性计算]
    C --> E
    V[三方模型 Endpoint] --> G[模型网关]
    O --> F[报告/导出/备份]
    E --> A[执行平面]
~~~

大对象通过 OSS 引用交接，事务状态和授权元数据通过 PostgreSQL 交接，证据引用绑定对象版本。数据区域不接受模型生成的 ACL、SQL、Endpoint 或对象路径作为授权依据。

## 3. 组件职责与存储

| 组件 | 详细职责 | 首选存储/边界 |
|---|---|---|
| Source Connectors | 连接制度、研报、公告、运营数据和指标系统，保存来源、许可、更新时间和同步状态 | 只读连接器；凭据由密钥系统注入 |
| Object Storage | 保存原文、附件、OCR、解析大对象、证据包、报告、导出和归档 | 阿里云 OSS；私有访问、版本、KMS/服务端加密、生命周期和短时签名 |
| Metadata Store | 保存文档、ACL、索引、Run、Approval、版本、删除任务和对象 URI | PostgreSQL；事务状态不依赖 OSS |
| Search/Evidence | ACL、effective_at、新鲜度、混合召回、重排和引用绑定 | 索引保存 chunk ID、ACL 版本、语料 manifest 和构建状态 |
| Metrics/Business Views | 提供金额、收益率、汇率、估值、同比/环比和受控只读视图 | 只读副本/业务指标服务；统一币种、单位、期间、日历和舍入 |
| Model Provider Boundary | 通过模型网关接入当前 OpenAI 兼容三方端点和后续供应商 | 生成、Embedding、Reranker、OCR、评测均走同一数据矩阵 |
| Backup/Retention | 执行对象、数据库、索引、审计、评测集和 Trace 的备份、保留、删除和恢复 | 独立 OSS bucket/账号或机构批准的 WORM 能力 |

## 4. 数据处理流程

1. 连接器接收源对象，做恶意文件、宏、大小、许可和密级检查。
2. 解析/OCR 在受限环境完成，原文和中间结果写入带版本的 OSS 对象。
3. 继承源系统 ACL，生成 chunk、Embedding 和关键词索引；索引记录 ACL、时间和来源版本。
4. 检索请求携带服务端 principal、Workspace、effective_at 和数据范围，先过滤后重排。
5. 证据服务返回 document_id、chunk_id、页码/表格位置、版本、来源和新鲜度，不由模型编造 URL。
6. 指标服务返回带时间戳和口径的输入，确定性函数生成计算结果；Deep Agent 负责解释。
7. 生成报告、证据包和导出文件写入加密 OSS；下载重新鉴权并使用短时 URL。
8. 删除使用 tombstone，沿索引、缓存、Checkpoint、摘要、导出、评测集、Trace 和备份 lineage 传播。

## 5. 数据快照与可重现性

每个投研 Run 固定语料 manifest、ACL/IAM 快照、行情、汇率、指标、计算函数、索引、模型 profile 和资料可知时间。回答历史日期问题只使用当时可用资料。原文、chunk、向量、摘要、Checkpoint、草稿、导出和备份都带来源依赖、密级和内容哈希，权限撤销后不能继续进入模型上下文。

模型处理矩阵逐阶段记录数据类型、密级、PII/原文、处理地域、允许供应商、脱敏方式、缓存/保留期、删除触发器和责任人。Embedding、Reranker、OCR、评测裁判、fallback、索引构建和备份不得被遗漏；高密级原文默认不发送三方。

## 6. 失败、删除与恢复

ACL 同步过期或失败时拒绝敏感检索；索引、缓存、OSS、数据库或模型服务不可用时返回可行动的缺口，不降低权限。删除任务记录每个 lineage 节点的成功、失败、重试和完成证明；法律冻结对象只限制业务可见性，不绕过 WORM。恢复演练覆盖 OSS 版本、PostgreSQL 状态、索引 manifest、审计哈希链和 RPO/RTO。

## 7. 验收条件

- 历史日期查询绑定语料、行情、汇率、指标和 ACL 快照，不使用未来资料。
- 撤权后的检索、引用、缓存、历史上下文和导出均失败或重新生成。
- Embedding、Reranker、OCR、评测和 fallback 的供应商、地域、留存和删除规则可逐行追溯。
- OSS 签名 URL、浏览器缓存、压缩包、宏、HTML/PDF、CSV 公式注入和高密级前端预览通过测试。
- 备份与恢复保持同等级加密和访问控制；WORM、哈希链、legal hold 和删除证明可以核验。
