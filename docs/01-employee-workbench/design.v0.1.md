## 1. 范围与边界

本模块覆盖：应用目录、对话、附件、任务进度、引用跳转、草稿编辑、审阅、导出和反馈。

依赖：总蓝图、Run 服务、平台管理、知识服务、工具网关、模型网关或观测与审计（按本模块职责取其必要部分）。

本模块不能改变 Tenant、Workspace、数据密级、AgentVersion、审批、审计或生产准入规则；共用约束以总蓝图 v0.2 第 0 节和第 13 节为准。

## 2. 接口与交接

- POST /runs 使用 Idempotency-Key；GET /runs/{id}/events 使用 after_seq 游标；下载每次鉴权并记录水印、密级和哈希。

## 3. 验收条件

- 验证越权标题/正文/附件不可见，重复创建幂等，撤权和删除状态可见，浏览器缓存、XSS、公式注入和恶意附件测试通过。
