## 1. 范围与边界

本模块覆盖：任务创建、异步队列、状态查询、事件流、取消、恢复、定时入口和幂等。

依赖：总蓝图、Run 服务、平台管理、知识服务、工具网关、模型网关或观测与审计（按本模块职责取其必要部分）。

本模块不能改变 Tenant、Workspace、数据密级、AgentVersion、审批、审计或生产准入规则；共用约束以总蓝图 v0.2 第 0 节和第 13 节为准。

## 2. 接口与交接

- POST /runs 返回 202、run_id 和 status_url；GET 返回 state_version；更新/取消/审阅使用 If-Match；事件使用 event_seq/event_id/after_seq。

## 3. 验收条件

- 验证数据库提交点、outbox、下游超时、租约过期和重复消息的恢复；CAS/fencing 阻止旧 Worker 写入。
