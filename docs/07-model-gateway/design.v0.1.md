## 1. 范围与边界

本模块覆盖：统一模型接口、第三方 OpenAI 兼容端点、模型白名单、密级路由、容量、成本和输入输出治理。

依赖：总蓝图、Run 服务、平台管理、知识服务、工具网关、模型网关或观测与审计（按本模块职责取其必要部分）。

本模块不能改变 Tenant、Workspace、数据密级、AgentVersion、审批、审计或生产准入规则；共用约束以总蓝图 v0.2 第 0 节和第 13 节为准。

## 2. 接口与交接

- invocations 只接受已发布 profile_id、数据分类、脱敏消息和预算；routes/evaluate 返回允许模型和策略 ID；profile 可停用。

## 3. 验收条件

- 高密级、未脱敏 PII、无供应商批准或跨境不明请求硬拒绝；模型升级需通过中文金融、结构化输出、工具和数值回归。
