## 1. 范围与边界

本模块覆盖：LangSmith Cloud 调试与评测、脱敏 Trace、独立金融审计、不可篡改归档和删除留存。

依赖：总蓝图、Run 服务、平台管理、知识服务、工具网关、模型网关或观测与审计（按本模块职责取其必要部分）。

本模块不能改变 Tenant、Workspace、数据密级、AgentVersion、审批、审计或生产准入规则；共用约束以总蓝图 v0.2 第 0 节和第 13 节为准。

## 2. 接口与交接

- trace-policy 固定字段白名单；audit-events 只接受服务端签名事件；retention/deletions 返回 lineage 节点状态和完成证明。

## 3. 验收条件

- Trace 禁止原始 Prompt、附件、检索正文、完整工具响应、账户标识和隐藏推理；审计使用可信时钟、序号、哈希/签名、WORM、跨区副本和双人控制。
