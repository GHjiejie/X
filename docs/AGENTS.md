# 文档维护约束

本目录遵循用户明确要求：按平台能力分类，所有设计更新新增带版本号的文件，不覆盖旧文档。

- 修改设计前，读取版本号最高的 `catalog.v*.md`、`versioning.v*.md` 和目标模块的相关版本。版本按数字比较，不按文件名字符串排序。
- 所有已有设计文件、蓝图、目录索引、版本规范、ADR 和评审文档均视为不可变历史；不得原地修改、删除、重命名或移动，包括未带版本号的历史文件。
- 更新时创建新的 `<文档名>.v<主版本>.<次版本>.md`，同时写明文档 ID、版本、日期、状态、上一版本、依据和变更摘要。版本号不能复用。
- 本次新建模块的初始版本为 v0.1；后续增补或修正使用 v0.2、v0.3；职责或契约发生不兼容变更时升级主版本。
- 文件在同一次尚未交付的编写过程内可以完善；交付、进入评审、被其他文档引用或提交后，必须新增版本，不能继续改旧文件。
- 新增或更新模块后，新增更高版本的 `catalog.v*.md`，显式固定本次文档集所用的各模块版本。历史索引同样不覆盖，不维护可变的 latest 文件或符号链接。
- 使用指向具体版本文件的相对链接。旧版本的链接、状态和正文保持原样；废弃、替代和纠错说明写入新版本。
- `financial-agent-platform-blueprint.md` 是原始历史文件；`00-architecture/financial-agent-platform-blueprint.v0.2.md` 是其逐字节副本，不代表内容重新审批。
- 保持既有范围：Deep Agents 优先，OSS 存储大对象、数据库保存事务状态，三方模型受网关控制，不自建 Agent 可观测体系，LangSmith Cloud 的生产使用受 P0 门禁约束。
- 拆分、版本升级和文档齐备不代表功能已实现、测试已通过、凭据已轮换或生产已获批准。
- 不读取或复制凭据来填充文档；不修改本次任务之外的用户工作区变更。

本文件是文档工作指令入口，不承载产品设计。版本规范的后续更新也通过新增 `versioning.v*.md` 保存。
